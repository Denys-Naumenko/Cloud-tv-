# 📺 Cast4K

Фільм, скачаний на MacBook → одна кнопка → дивишся на Android TV у повній 4K-якості.

Працює через **Chromecast built-in** (є майже в усіх Android TV / Google TV). Mac стає маленьким
медіасервером у твоїй Wi-Fi, а телевізор сам тягне файл напряму — **не трансляція екрана**,
тому картинка без стиснення і без лагів, а ноутбук можна закрити кришкою... ну майже (див. нижче).

## Як запустити (перший раз ~2 хв)

1. Завантаж репозиторій на Mac (`git clone` або Code → Download ZIP).
2. Якщо ще немає [Homebrew](https://brew.sh) — встанови (одна команда з сайту).
3. Двічі клікни **`Cast4K.command`**.
   - Якщо macOS скаже «не можна відкрити» → правий клік → *Open* → *Open*.
   - Перший раз він сам встановить `ffmpeg` і залежності.
4. Відкриється сторінка в браузері: обираєш ТВ, обираєш фільм, тиснеш **▶︎ Дивитись на ТВ**. 🍿

Фільми шукаються в `~/Downloads`, `~/Movies`, `~/Desktop`. Інші папки:
`./Cast4K.command --folder "/Volumes/Disk/Кіно"`. Або просто встав шлях до файлу на сторінці.

## Що вміє

- **4K / HDR10 / HEVC / H.264** — відео не перекодовується взагалі, йде біт-у-біт.
- **MKV** — перепаковується в MP4 на льоту (миттєво, без втрати якості).
- **DTS / TrueHD / FLAC** звук → AAC 5.1 (Chromecast їх не грає); AC3/EAC3/AAC — як є.
- Вибір аудіодоріжки (наприклад, укр. дубляж) і **субтитрів** (з MKV або `фільм.srt` поруч).
- Пульт на сторінці: пауза, перемотка ±30с, повзунок, гучність.

## Якщо щось не так

| Проблема | Що робити |
|---|---|
| ТВ не знаходиться | ТВ увімкнений і в тій самій мережі? Перевір, що в Chrome на Mac є кнопка «Транслювати» на твій ТВ. Дозволь Python доступ до локальної мережі (macOS спитає). |
| Мережа «гостьова» / з ізоляцією клієнтів | Вимкни AP isolation на роутері — інакше ТВ не бачить Mac. |
| Брандмауер macOS питає про вхідні з'єднання | Тисни «Дозволити» — ТВ має забрати файл з Mac. |
| Гальмує на важких ремуксах (60+ Мбіт/с) | Краще ставити Mac ближче до роутера / на 5 ГГц. |
| Mac заснув і фільм зупинився | Не закривай кришку або запусти `caffeinate -d` в Терміналі. |
| Dolby Vision показує дивні кольори | Деякі ТВ не вміють DV profile 7 — бери реліз з HDR10. |

## Як це влаштовано

```
Mac: cast4k (Python)  ── HTTP :8765 ──▶  Android TV (Chromecast Default Media Receiver)
  ├─ сторінка-пульт (тільки для localhost)
  ├─ /file/<id>   — MP4 як є, з Range (нативна перемотка)
  ├─ /live/<id>   — ffmpeg -c:v copy → fragmented MP4 (перемотка = перезапуск з позиції)
  └─ /subs/<id>   — субтитри у WebVTT
```

Ручний запуск без `.command`: `pip install -r requirements.txt && python3 -m cast4k`.
Дебаг: `CAST4K_DEBUG=1 python3 -m cast4k`.
